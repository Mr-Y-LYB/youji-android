游迹 Windows v1.3.2

安装：解压整个 ZIP，双击「Install.cmd」。安装后从 Windows 开始菜单打开「游迹」。
如只需直接运行，也可从 Release 单独下载 YouJi-Windows-v1.3.2.exe。
无需管理员权限。运行需要 Microsoft Edge；Windows 10/11 通常已安装。

数据保存在 %LOCALAPPDATA%\YouJi\games.json，封面在同目录的 covers 文件夹。
建议定期在应用设置中导出 JSON 备份。手机与 Windows 可互相导入此备份；手动封面也会随备份迁移。

Windows 版支持手动添加、Steam 名称联想与封面、Steam 成就清单、逐项勾选、手动选图、JSON/CSV/TSV/Excel/文字文件导入和 JSON 备份。
目前 Windows 版不支持直接识别小黑盒截图；可使用手机端截图识别，再通过 JSON 备份迁移，或在 Windows 版粘贴文字导入。

卸载程序：删除 %LOCALAPPDATA%\Programs\YouJi 文件夹以及开始菜单中的「游迹」快捷方式。
卸载程序不会自动删除个人记录；如需清除，再手动删除 %LOCALAPPDATA%\YouJi。
